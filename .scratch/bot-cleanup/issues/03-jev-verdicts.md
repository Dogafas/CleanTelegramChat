# 03: Jev-вердикт для ботов

**What to build:** Тексты бота и его описание уходят в Jev на смысловой вердикт; «рекламная витрина» ловится семантикой, даже если локальные регулярки её не поймали. Причины из вердикта показываются в чекбоксах.

**Blocked by:** 02

**Status:** resolved

- [x] `evaluate` переиспользуется как есть: имя бота → `channel`, bio (≤ 500 символов) → `description`, тексты бота → `posts`; ключи state остаются `channel` / `description` / `posts`, чисел в state нет
- [x] Jev-вердикт `ads` вместе с «не использован» даёт RED
- [x] Нет текстов или ошибка вердикта → GRAY
- [x] Маппинг полей и маршрутизация вердикта покрыты тестами (по образцу тестов вердикта)
