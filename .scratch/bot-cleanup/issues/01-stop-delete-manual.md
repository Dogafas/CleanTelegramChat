# 01: Стоп и удалить бота вручную

**What to build:** Пользователь запускает сценарий чистки ботов, видит список всех бот-диалогов (включая архивные), выбирает бота и выполняет «Остановить» (блокировка) и/или «Удалить диалог». Стоп обратим через журнал отката со state-guard; удаление фиксируется как не восстановимое. Минимальный сквозной путь: скан → выбор → действие → журнал.

**Blocked by:** None (can start immediately)

**Status:** resolved

- [x] Сценарий показывает все бот-диалоги, включая архивные
- [x] Выбранный бот останавливается (блокировка); запись отката попадает в журнал, откат снимает блокировку только если пользователь не трогал её вручную (state-guard)
- [x] Удаление диалога выполняется и фиксируется в журнале как не восстановимое
- [x] Все мутации проходят через flood-retry
- [x] План-действия ботов покрыты тестами через фейковый клиент (по образцу тестов плана); новый модуль ядра и сценарий зарегистрированы в тесте слоёв
