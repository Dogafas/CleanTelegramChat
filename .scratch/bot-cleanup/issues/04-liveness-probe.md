# 04: Глубокая проверка пробой /start

**What to build:** Opt-in режим «глубокая проверка»: боту отправляется `/start`, 30 секунд ожидания ответа; тишина даёт признак «не отвечает на /start» → RED. По умолчанию режим выключен — живые боты не получают сообщений без явного выбора пользователя.

**Blocked by:** 02

**Status:** resolved

- [x] Ответ бота в течение ожидания не даёт признака
- [x] Отправка идёт через flood-retry
- [x] Проба покрыта тестом через фейковый клиент с управляемым ожиданием
