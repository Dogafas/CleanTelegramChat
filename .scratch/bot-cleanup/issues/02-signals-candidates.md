# 02: Сигналы и кандидаты RED/YELLOW/GRAY

**What to build:** Скан вычисляет фиксированные сигналы по полной истории каждого бот-диалога и сортирует кандидатов: RED (предотмечен) / YELLOW / GRAY (без отметки). Пользователь видит чекбоксы с причинами и вручную подтверждает список перед любым действием.

**Blocked by:** 01

**Status:** resolved

- [x] Полная история диалога выгружается постранично; счёт исходящих ведётся за всю историю, не по срезу
- [x] Пять сигналов считаются по зафиксированным порогам: молчание ≥ 3 мес.; ≤ 1 исходящего за всю историю; ≥ 3 входящих после последнего исходящего; реклама ≥ 25% по общему маркер-регулярному выражению и URL-entities; удалён/забанен
- [x] Удалён/забанен бот попадает в RED сразу, без дополнительных проверок
- [x] Кандидаты отсортированы RED → YELLOW → GRAY, RED предотмечен, остальные нет
- [x] Ни одно действие не выполняется без ручного подтверждения
- [x] Сигналы и маршрутизация покрыты тестами через фейковый клиент (по образцу тестов обзора подписок)
