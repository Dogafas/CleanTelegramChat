# Clean Telegram Chat

Инструмент автоматизированной очистки собственных сообщений пользователя в групповых чатах Telegram.

## Language

**Target Chat**:
Чат, в котором аккаунт состоит и который выбран для удаления его сообщений: публичная супергруппа, закрытая супергруппа или обычная группа.
_Avoid_: dialog, channel, left chat, личка

**Public Supergroup**:
Супергруппа с username. Аккаунт в ней состоит.
_Avoid_: channel, public chat

**Private Supergroup**:
Супергруппа без username. Аккаунт в ней состоит.
_Avoid_: closed chat, secret chat, left chat

**Basic Group**:
Обычная группа, не супергруппа. Аккаунт в ней состоит.
_Avoid_: supergroup, closed chat

**Left Chat**:
Чат, в котором аккаунта уже нет. Не Target Chat: свои сообщения там удалить нельзя.
_Avoid_: archived dialog, private supergroup

**Supergroup**:
Тип группового чата в Telegram с расширенными возможностями администрирования и истории сообщений.
_Avoid_: group, channel

**Message Purge**:
Процесс пакетного поиска и безвозвратного удаления сообщений текущего пользователя в выбранном Target Chat.
_Avoid_: clean, wipe, clear

**Message Batch**:
Фиксированная порция найденных сообщений пользователя (обычно до 100 штук), удаляемая за один сетевой запрос с соблюдением интервалов троттлинга.
_Avoid_: chunk, pack, slice

**Telegram Session**:
Персистентное состояние авторизации клиента (файлы сессии и API-ключи), обеспечивающее доступ к Telegram без повторного прохождения двухфакторной аутентификации.
_Avoid_: auth cache, token, credentials

**Session Directory**:
Выделенная папка `sessions/` в корне проекта для хранения персистентных файлов сессий Telegram (`*.session`).
_Avoid_: session folder, accounts dir

**Session Name**:
Идентификатор сессии (имя файла без расширения `.session`), задаваемый пользователем.
_Avoid_: account id, login

**All Sessions**:
Режим последовательной пакетной очистки сообщений во всех сессиях из `Session Directory`.
_Avoid_: batch all, multi session

**Channel Subscription**:
Публичный канал (`ChatType.CHANNEL`), на который подписан аккаунт. Объект оценки и отписки; не Target Chat — сообщения в нём не чистятся.
_Avoid_: dialog, группа, подписка на юзера

**Quality Metric**:
Числовая характеристика канала, вычисляемая локально из последних постов и карточки канала (ERR, ER, вариативность просмотров, доля рекламных постов и т.д.). Нормируется в скор 0–100.
_Avoid_: статистика, аналитика

**Quality Score**:
Суммарная локальная оценка канала 0–100: взвешенная сумма скоров по Quality Metric со штрафными жёсткими флагами накрутки. 100 — здоровый канал.
_Avoid_: рейтинг, ERR

**Unsubscribe Candidate**:
Channel Subscription в списке на отписку из-за Quality Score ниже порога, жёсткого флага накрутки или Текстового провала.
_Avoid_: плохой канал, спам

**Verdict**:
Оценка Jev по текстам постов Channel Subscription: Голос и Текстовый провал. Ставится каждой подписке с непустым текстом, не только кандидату.
_Avoid_: полезность, content, Category Assignment

**Голос**:
Один тип текстов канала: глубокий, новости, авторский юмор или пустой поток. Глубокий — в тексте есть непереносимая ставка, включая чужой пересланный разбор.
_Avoid_: content, тип контента, полезность

**Текстовый провал**:
Слоп, кликбейт, рекламная витрина, продажа курсов или Голос «пустой поток». Делает подписку Unsubscribe Candidate даже при высоком Quality Score.
_Avoid_: нейродетектор, интересность

**Нейрослоп**:
Формульный текст без ставки, который можно переставить в другой канал той же ниши. Не признак «написано ИИ». Если модель отметила и новость, и слоп, это нейрослоп.
_Avoid_: ИИ-текст, дайджест

**Кликбейт**:
Обещание в посте, которое видимый текст не отдаёт. Острый заголовок с ответом в теле — не кликбейт.
_Avoid_: интрига, давящий заголовок

**Авторскость**:
Непереносимая ставка в тексте: имя, цифра, наблюдение или причинный механизм. Не признак того, что канал написал текст сам.
_Avoid_: оригинальность, человеческий текст

**Авторский юмор**:
Голос со ставкой, но это юмор или наблюдения, а не польза для роста. Не пустой поток и не нейрослоп.
_Avoid_: noise, интересность

**Sortable Dialog**:
Канал, в том числе без username, или группа, в которой аккаунт ещё состоит: публичная супергруппа, закрытая супергруппа или обычная группа. Архив входит.
_Avoid_: личка, бот, Left Chat, папка

**Category**:
Имя одной непустой строки из файла категорий. Один Sortable Dialog может входить в несколько Category.
_Avoid_: вкладка, Verdict, тип контента

**Category Assignment**:
Ответ Jev, входит ли один Sortable Dialog в одну Category. Не Verdict.
_Avoid_: вердикт, скор, Quality Score

**Uncategorized**:
Sortable Dialog, по которому Jev ответил и не дал ни одной Category.
_Avoid_: не оценено, мусор

**Unevaluated**:
Sortable Dialog, по которому вызов Jev не удался.
_Avoid_: без категории

**Chat Folder**:
Вкладка Telegram с именем Category. Не Session Directory и не архив.
_Avoid_: папка, папочка, folder_id

**Sort File**:
Файл `sort-<сессия>.md`: какие Sortable Dialog в каких Category. Не список созданных вкладок.
_Avoid_: кэш, журнал
