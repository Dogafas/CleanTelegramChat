# Clean Telegram Chat

Программа предназначена для автоматического удаления всех пользовательских сообщений из группового Telegram-чата. Она упрощает процесс очистки вашей истории сообщений в групповых чатах с большой активностью участников и большим количеством сообщений. Ручное удаление может быть трудоемким и требует значительного времени, особенно если необходимо проматывать историю сообщений для поиска собственных записей. Программа решает эту проблему, предоставляя возможность массово удалить ваши сообщения из выбранного вами группового чата.

---

## Вам обязательно понадобится

1. Войти на сайт [my.telegram.org](https://my.telegram.org/).
2. Выбрать ссылку **API development tools**.
3. Создать автономное приложение.
4. Скопировать **app_id** и **app_hash**.
5. (При первом запуске скрипт запросит у вас API ID и API HASH, и сохранит их в файл `.env`.)
6. (Если серверы Telegram недоступны напрямую, допишите в уже существующий `.env`: `TELEGRAM_PROXY_SCHEME=socks5`, `TELEGRAM_PROXY_HOSTNAME`, `TELEGRAM_PROXY_PORT`. Логин и пароль — `TELEGRAM_PROXY_USERNAME` и `TELEGRAM_PROXY_PASSWORD`, только парой. Допустимые схемы: `socks5`, `socks4`, `http`. Ссылка `tg://proxy` не поддерживается.)

## Установка и запуск

1. Установите [uv](https://docs.astral.sh/uv/) и выполните `uv sync` (или `install.bat`).

Без uv — стандартный pip (Python 3.10–3.12):

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

2. Запуск: `uv run python clean_my_messages.py` (или `start.bat`); без uv — `python clean_my_messages.py` из активированного окружения.
3. Список участников: `uv run python people.py CHAT_ID [SESSION_NAME]` (без `SESSION_NAME` используется сессия `cleaner`).
4. Отписка от каналов по качеству контента: `uv run python clean_my_subs.py` — детали в разделе [«Очистка подписок от каналов»](#очистка-подписок-от-каналов-clean_my_subspy).
5. Раскладка чатов по категориям: `uv run python sort_chats.py` — детали в разделе [«Раскладка чатов по категориям»](#раскладка-чатов-по-категориям-sort_chatspy).
## Очистка подписок от каналов (clean_my_subs.py)

Оценивает каналы в подписках по текстам постов (Jev) и локальным метрикам, формирует список кандидатов с цветовой приоритизацией и выполняет отписку только после явного подтверждения.

### Настройка вердиктов LLM (опционально)

Без ключа кандидаты показываются с локальными метриками, без вердикта LLM. Ключ берётся с [console.typesafe.ai](https://console.typesafe.ai) или используется OpenRouter — допиши в `.env` (формат — см. `.env.example`):

```env
# Через OpenRouter:
TYPESAFE_API_KEY=sk-or-...
TYPESAFE_BASE_URL=https://openrouter.ai/api
# Напрямую TypeSafe (base_url можно не указывать):
# TYPESAFE_API_KEY=ts-...
# Модель (по умолчанию jev-latest):
# TYPESAFE_DEFAULT_MODEL=jev-latest
```

Значения из `.env` подхватываются автоматически и не перезатираются при перезаписи `.env`; переменные, уже установленные в окружении, имеют приоритет.

### Запуск

```bash
uv run python clean_my_subs.py
```
1. Выбери сессию.
2. Скрипт собирает подписки на каналы и по последним 30 постам каждого считает локальные метрики и сведения о покрытии выборки. Медиальбомы объединяются в единые публикации, техническое число сообщений и число публикаций разделены.
3. Если в публикациях есть текст, Jev ставит голос (`глубокий` / `новости` / `авторский юмор` / `пустой поток`) и семантические проверки текстового провала. Модельная выборка отбирается детерминированно и равномерно по времени, а число обрезанных текстов фиксируется в покрытии выборки.
4. Открывается главное меню управления диетой и режимами чтения:
   - **Кандидаты и режимы чтения**: список каналов с цветовой приоритизацией (Красный `[Отписаться]`, Жёлтый `[Проверить]`, Серый `[Недостаточно данных]`). Для выбранных каналов можно запланировать:
     - `Отписаться` — покинуть канал (несовместимо с режимами чтения);
     - `Без звука` — отключить уведомления;
     - `В архив` — архивировать канал (совместимо с mute);
     - `В папку чтения` — добавить в указанную папку диалогов Telegram без удаления из существующих фильтров;
     - `Очистить` — снять запланированное действие.
   - **Обзор пересечений каналов**: линейный локальный поиск точных межканальных дублей текстов, чистых пересылок и общих URL первоисточников в сопоставимом временном окне. Асимметричный расчёт долей совпадений и просмотр примеров.
   - **Уточнить выбранные каналы**: сбор расширенной истории (по умолчанию до 14 дней и 200 сообщений) для выбранных подписок. Не сдвигает снимок, обновляет статус покрытия, повторно запрашивает вердикт и пересчитывает пересечения.
   - **Просмотреть и применить план действий**: сводка всех изменений. При попытке отписаться от всех источников дублирующей темы выдаётся явное предупреждение о потере всех копий. Применение проверяет актуальное состояние в Telegram, не делает лишних сетевых вызовов и сохраняет локальный журнал отката.
   - **Откатить изменения (Rollback)**: безопасный откат mute, архива и добавления в папки чтения. Если пользователь изменил настройку вручную в Telegram, откат не затирает её. Отписка помечена как необратимая.

Пороги метрик — в `THRESHOLDS` (`subs.py`); методология — `docs/adr/0007-subscription-quality-scoring.md`, `docs/adr/0009-text-fail-unsubscribe.md` и `docs/information-diet-next-implementation.md`.
## Раскладка чатов по категориям (sort_chats.py)

Классифицирует все каналы и группы аккаунта (включая закрытые и архивные) по категориям из текстового файла и предлагает создать новые вкладки в Telegram.

1. Категории — строки в `categories.txt` рядом со скриптом, либо путь в `CATEGORIES_FILE` (процесс или `.env`). Пустой файл и имена `без категории` / `не оценено` останавливают запуск. Длиннее 12 символов попадает в файл, но не в заголовок вкладки.
2. В `.env` нужен `TYPESAFE_API_KEY`. Без ключа файл не пишется.
3. `uv run python sort_chats.py`. Одна сессия, пункта «Все сессии» нет.
4. Скрипт пишет `sort-<сессия>.md` и кэш `sort-<сессия>.cache.json`. Повтор с теми же категориями и теми же 30 текстами Jev не зовёт. Историю качает снова. Если история не прочиталась, Jev решает по названию, username и описанию, и этот ответ в кэш не пишет.
5. Чекбокс вкладок пустой. Существующую вкладку с тем же именем скрипт не меняет. Подтверждение `Создать N вкладок?` обязательное. Нет — файл остаётся, Telegram не трогается.
## Сессии

Файлы сессий хранятся в папке `sessions/`. Старый файл `cleaner.session` из корня проекта переносится туда автоматически при первом запуске.

При запуске `clean_my_messages.py` появляется меню:

- выбрать одну из существующих сессий;
- **Все сессии** — последовательная очистка во всех аккаунтах (появляется, если сессий больше одной);
- **+ Создать новую сессию** — введите имя, для новой сессии пройдите аутентификацию;
- **- Удалить сессию** — удаление с подтверждением.

## Аутентификация
При запуске программа потребует от вас ввести в строку **Enter phone number or bot token:** свой номер телефона в международном формате, например: +79874561122.
Подтвердить правильность ввода номер, введя **y** и нажав Enter.
Ввести **код для входа в Telegram**, который придет вам на телефон.
(Если у вас установлена двухфакторная авторизация, ввести пароль).

### Пример использования
1. Выберите сессию (или создайте новую).
2. Отметьте пробелом нужные чаты в списке и нажмите Enter для подтверждения.
3. Скрипт начнет удаление ваших сообщений из выбранных чатов. Дождитесь завершения программы.
