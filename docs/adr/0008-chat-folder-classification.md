# Classify every sortable dialog; never rewrite an existing chat folder

Sorting chats is a different job from unsubscribe scoring. Jev runs on every channel and group the account still belongs to, including archived and private channels, with the last 30 messages when history is readable. ADR 0007 keeps Jev off non-candidates for unsubscribe; that gate does not apply here, because a missing category is not a quality score. The durable result is the Sort File. A Chat Folder is created only for a checked Category whose title is at most 12 characters and whose exact title is not already a folder. Existing folders are never updated, including folders this tool created on a previous run: a re-run refreshes only the Sort File, and rebuilding a tab means deleting it in Telegram first. Archived dialogs go into `include_peers`, so they show up in the new tab.

Considered and rejected: merging or replacing an existing folder (drops or freezes hand-added chats; the user chose never to touch an existing title); Jev only on unsubscribe candidates (leaves most dialogs unclassified); a single Choice label (a dialog belongs to several categories); leaving archived dialogs out of tabs (the user chose to place them in the folder).

Distinction from Reading Mode Folder (`chat_folder.py`, ADR 0010):
While `sort_chats.py` never mutates or overwrites existing folders, the subscription reading mode "add to folder" (`add_peer`) specifically appends a single channel to an existing folder by preserving its full configuration (`include_peers`, `exclude_peers`, `pinned_peers`, filters) without replacing the folder rule.
